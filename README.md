## ☁️ MedLoad — AWS Cloud Application

A cloud-based application designed to provide information about clinic loads and availability using a serverless AWS architecture.

### Architecture
- React frontend
- Static hosting with Amazon S3
- Content delivery through CloudFront
- User authentication with Amazon Cognito
- REST API using API Gateway
- Serverless backend with AWS Lambda
- Data storage using DynamoDB
- Scheduled cloud operations with EventBridge

### Tech Stack
`AWS` `Lambda` `API Gateway` `DynamoDB` `Cognito` `S3` `CloudFront` `EventBridge` `React`
